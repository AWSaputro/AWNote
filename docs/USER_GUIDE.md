## 1. Memulai (Dashboard & Organisasi)

### Membuat Catatan Baru
- Klik tombol mengambang bundar **`(+)`** di **sebelah kiri bawah layar**.
- Catatan baru langsung terbuka dalam hitungan detik.

### Mengorganisir Catatan dengan Folder
- Pada sidebar sebelah kiri, klik **`[+ Folder Baru]`**.
- Beri nama folder (misal: *Kuliah*, *Kerja*, *Sketsa*).
- Anda dapat menyeret (*drag & drop*) kartu catatan ke dalam folder yang diinginkan.

### Mencari Catatan
- Gunakan bilah pencarian di bagian atas untuk memfilter catatan berdasarkan **judul** atau **tag** (`#ujian`, `#meeting`).

## 2. Ruang Kerja Kanvas (Editor)

### Memilih Format Kertas
Klik ikon **Menu Lembar `[📄]`** di bilah atas untuk memilih:
- **Mode Halaman (A4)**: Lembaran kertas berhalaman terpisah. Ideal untuk catatan formal yang akan dicetak atau diekspor ke PDF.
- **Kanvas Tanpa Batas (*Infinite Canvas*)**: Kanvas membentang bebas tanpa batas tepi. Cocok untuk *mind-mapping*, diagram alir, dan *brainstorming*.

### Mengganti Template Kertas
Pilih latar belakang kertas sesuai kebutuhan Anda:
- **Polos (*Blank*)**: Bersih tanpa garis.
- **Bergaris (*Ruled*)**: Garis horizontal seperti buku tulis.
- **Kotak-kotak (*Grid*)**: Sangat membantu untuk membuat tabel, grafik, dan rumus matematika.
- **Titik-titik (*Dot Grid*)**: Cocok untuk *bullet journaling* dan sketsa UI.
- **Unggah Template Kustom**: Anda dapat mengunggah gambar latar belakang sendiri (misal: lembar perencanaan agenda/perencana harian).

### Menyesuaikan Posisi Toolbar Alat (Dock)
Bilah alat tulis (*Floating Pen Dock*) dapat diubah posisinya melalui menu tampilan:
- **Atas / Bawah**: Menempel rapi di tepi atas atau bawah layar.
- **Kiri / Kanan**: Sangat ergonomis untuk pengguna kidal atau tablet vertikal.
- **Bebas (*Floating*)**: Bebas digeser ke sudut layar mana saja.

## 3. Panduan Alat Tulis (Inking Tools)

Setiap alat memiliki fungsi dan sensasi goresan tersendiri:

### 🖊️ Pen (Pulpen Tinta)
- **Karakter**: Garis solid dan tajam, sangat sensitif terhadap tekanan stylus/S-Pen.
- **Pengaturan**: Tekan ikon Pen untuk memilih warna (palet cepat atau pemilih HEX) dan slider ketebalan garis.

### ✏️ Pensil (Sistem Grade Standar)
Tidak perlu bingung mengatur piksel! Pensil AwNotes menggunakan grade standar yang familiar:
- **`2H` / `H`**: Abu-abu muda, garis tipis keras. Bagus untuk sketsa dasar dan garis bantu.
- **`HB`**: Abu-abu netral seimbang, ketebalan sedang. Standar tulisan pensil sehari-hari.
- **`2B`**: Hitam gelap empuk, responsif terhadap tekanan. Pilihan terbaik untuk catatan harian.
- **`4B` & `6B`**: Hitam pekat berbutir (*grainy*). Sangat cocok untuk mengarsir gambar (*shading*).

### 🖌️ Stabilo / Highlighter
- Memiliki efek *multiply blend*. Warna stabilo semi-transparan dan **tidak akan pernah menutupi tulisan tinta atau teks di bawahnya**.

### 🧹 Penghapus (Eraser)
- **Stroke Eraser**: Sentuh sedikit bagian garis, seluruh tarikan garis tersebut langsung terhapus rapi.
- **Pixel Eraser**: Menghapus area kanvas secara manual seperti karet penghapus fisik.

### 📐 Objek Dasar Geometri
- Klik ikon geometri untuk memilih: **Garis Lurus**, **Kotak**, **Lingkaran/Elips**, **Segitiga**, atau **Bintang**.
- **Fitur Cerdas "Hold to Snap"**: Anda juga bisa menggambar lingkaran atau garis miring menggunakan Pen biasa, lalu **tahan stylus diam selama 0,5 detik di akhir goresan** — garis otomatis lurus dan lingkaran otomatis sempurna!

### ✂️ Lasso Tool (Seleksi Bebas)
- Lingkari area tulisan atau gambar yang ingin Anda kelola.
- Setelah dilingkari, Anda dapat:
  - Menggeser posisinya ke baris lain.
  - Memperbesar atau memperkecil ukuran tulisan.
  - Mengubah warna tulisan sekaligus (misal: dari hitam menjadi merah).
  - Menyalin (*copy*) atau menghapus area yang dipilih.

## 4. Menggunakan Pad Penulisan Mudah (Easy Writing Pad)

Fitur ini membantu Anda menulis catatan panjang secara rapi di layar HP atau tablet:

1. Aktifkan ikon **Pad Penulisan Mudah** di toolbar (atau tekan tombol **`Z`**).
2. Sebuah kotak target (*zoom box*) akan muncul di lembar catatan atas, dan jendela tulis besar muncul di layar bawah.
3. Tuliskan kata-kata Anda dengan ukuran besar dan leluasa di kotak bawah. Tulisan otomatis diperkecil dan diletakkan rapi di lembar catatan atas.
4. **Auto-Advance**: Saat tulisan Anda mendekati sisi kanan kotak, kotak target otomatis bergeser ke kanan untuk melanjutkan kata berikutnya.

## 5. Menyisipkan & Mengunci Gambar

### Memasukkan Gambar
- **Cara Cepat**: Salin gambar dari mana saja (screenshot), lalu tekan **`Ctrl + V`** di lembar catatan.
- **Cara Manual**: Klik tombol sisipkan gambar untuk memilih berkas dari galeri perangkat.

### Mengubah Ukuran & Mengunci Gambar
- Klik gambar untuk menampilkan 8 titik kendali (*handles*) untuk memutar atau mengubah ukuran gambar.
- **Kunci Gambar (*Lock Image*)**: Klik ikon gembok pada gambar. Setelah dikunci, gambar tidak akan bisa terseret secara tidak sengaja saat Anda mencoret-coret di atasnya menggunakan stylus.

---

## 6. Anotasi Dokumen PDF

1. Di Dashboard, klik tombol **"Import PDF"** dan pilih dokumen PDF yang ingin dipelajari.
2. Setiap halaman PDF akan dijadikan latar belakang kanvas beresolusi tinggi.
3. Anda dapat menggunakan stabilo untuk menandai paragraf buku, pulpen untuk memberi catatan tepi, atau mengisi formulir langsung di atas lembar PDF.
4. Klik **Menu > Ekspor PDF** untuk menyimpan dokumen gabungan (PDF asli + coretan tinta Anda) dalam format siap cetak.

---

## 7. Perekaman Suara Tersinkronisasi

1. Tekan tombol **Rekam Suara (Mikrofon)** di bilah atas saat mendengarkan kuliah atau rapat.
2. Mulailah menulis catatan seperti biasa.
3. Ketika audio diputar ulang (*playback*), setiap goresan tulisan tangan Anda akan **menyala (*highlight*) secara berurutan** mengikuti detik rekaman suara saat tulisan tersebut dibuat!

## 8. Cadangan Data (Offline & Google Drive)

### Mode Tamu (Tanpa Akun)
- Seluruh catatan Anda otomatis tersimpan di memori perangkat (**IndexedDB**). Aplikasi dapat dibuka dan digunakan tanpa koneksi internet.
- Anda dapat mengekspor berkas cadangan offline berformat **`.awn`** kapan saja melalui menu pengaturan.

### Mode Member (Login Google)
- Klik profil pengguna di kiri atas dan pilih **Login dengan Google**.
- Anda mendapatkan akses ke fitur cadangan awan:
  - **Cadangkan Catatan Ini**: Menyimpan salinan catatan yang sedang aktif ke folder `AwNotes_Backup/` di Google Drive pribadi Anda.
  - **Cadangkan Semua**: Mencadangkan seluruh koleksi catatan Anda sekaligus.
  - Privasi terjamin: AwNotes hanya bisa mengakses file cadangannya sendiri dan tidak dapat membaca berkas pribadi Anda yang lain di Google Drive.

## 9. Daftar Pintasan Keyboard (Shortcuts)

Semua tombol di bawah ini dapat dikustomisasi melalui menu **Pengaturan > Pintasan Keyboard**:

| Tombol Pintasan | Fungsi Alat |
| :---: | :--- |
| **`T`** | Beralih ke Mode Ketik Teks |
| **`P`** | Alat Pen (Pulpen Tinta) |
| **`B`** | Alat Pensil (Sketsa) |
| **`H`** | Alat Stabilo (Highlighter) |
| **`E`** | Alat Penghapus (Eraser) |
| **`L`** | Alat Seleksi Bebas (Lasso) |
| **`S`** | Menu Objek Bentuk Geometri |
| **`Z`** | Buka/Tutup Pad Penulisan Mudah |
| **`1` – `4`** | Pilih Slot Pena Favorit 1 sampai 4 |
| **`Ctrl + Z`** | Batalkan Goresan (Undo) |
| **`Ctrl + Y`** / **`Ctrl + Shift + Z`** | Ulangi Goresan (Redo) |
| **`Ctrl + V`** | Tempel (*Paste*) Gambar dari Clipboard |
