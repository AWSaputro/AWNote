# ⌨️ Alat: Mode Teks & Checklist To-Do

Mode **Teks** menyediakan fasilitas pengetikan teks digital yang berdampingan secara alami dengan lapisan kanvas tulisan tangan (*Hybrid Layer Overlay*).

---

## 1. Fitur Utama
- **Layer Overlay**: Teks diketik pada lapisan dasar dokumen, sementara kanvas gambar berada di atasnya secara transparan. Anda dapat mencorat-coret di atas teks atau menambahkan catatan di margin.
- **Checklist Interaktif**: Kotak centang to-do yang dapat diklik/centang langsung untuk membuat daftar tugas atau belanja.
- **Format Teks Ringkas**:
  - Tebal (*Bold*), Miring (*Italic*), Garis Bawah (*Underline*).
  - Pilihan ukuran font (Heading, Subheading, Body Text).
  - Daftar butir (*Bullet list*) dan daftar bernomor (*Numbered list*).

---

## 2. Pintasan Keyboard
- **Beralih ke Mode Teks**: Tombol **`T`**
- **Bold**: `Ctrl + B`
- **Italic**: `Ctrl + I`
